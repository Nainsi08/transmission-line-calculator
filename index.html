Transmission Line Constants Calculator

EE315 · Module 2 — generalized version. Handles arbitrary conductor construction (solid / N-bundle / N+1 composite / custom stranding), arbitrary phase-circuit geometry via coordinates, optional ground effect on capacitance, and temperature-corrected resistance — not just the one baseline case from the flowchart.

This tool solves the flowchart's baseline case out of the box (defaults below already match it), and generalizes further so it can be pointed at most Module‑2 problems: any bundle size, composite/ACSR conductors of any strand count, single/double/triple circuit or custom coordinate layouts, ground effect on capacitance, and temperature‑corrected resistance.
STEP 1

Conductor construction

Define the physical conductor used on every phase. GMR (for L) and equivalent radius (for C) are derived from geometry, not looked up from a table.
n sub-conductors assumed equally spaced on a circle (bundle ring). Works for any n ≥ 2 — not just 2/3/4-bundle; formula reduces to the textbook 2/3/4-bundle cases and the 1.09 correction factor automatically.
Generalized N/1 ACSR: n equal outer conducting strands touching a single non‑conducting core strand of the same radius (steel). Set n = 6 for the classic 6/1 ACSR. Overall radius = 3·rₛ; only the n outer strands carry current.
List only current-carrying strands (omit any non-conducting steel core). GMR and equivalent radius are computed exactly from the full set of pairwise strand distances — this covers any real stranded or multi-layer conductor.
